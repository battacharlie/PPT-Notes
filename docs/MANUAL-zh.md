# MEFISTOFELE DeckWhisperer – 使用手册（中文）

**Remote notes & control for PowerPoint**
[English](MANUAL-en.md) · [Italiano](MANUAL-it.md) · [Français](MANUAL-fr.md) · [Español](MANUAL-es.md) · [العربية](MANUAL-ar.md) · [中文](MANUAL-zh.md)

本手册中，**管理页面**是在运行 PowerPoint 的电脑上打开的页面；**远程页面**是您在手机上看到的页面。

MEFISTOFELE DeckWhisperer 会在演示进行时读取 PowerPoint 的**演讲者备注**，并实时显示
在您手机（或同一网络中任何设备）上打开的网页中。您还可以在手机上翻页、
跳转到指定幻灯片，并查看当前和下一张幻灯片。

## 系统要求
- 安装了桌面版 **PowerPoint** 的 **Windows 10/11**，或安装了 **PowerPoint for Mac** 的 **Mac**（macOS 12 或更高版本）。
- 电脑和手机处于**同一网络**（Wi-Fi 或网线）。

## 快速开始
**Windows**
1. 从 [Releases](https://github.com/battacharlie/PPT-Notes/releases) 页面下载 `mefistofele.exe`（最新版本）。
2. 双击运行。如果 Windows 显示“Windows 已保护你的电脑”：点击**更多信息 → 仍要运行**。首次启动时，请允许**专用网络**访问。

**Mac**
1. 从 [Releases](https://github.com/battacharlie/PPT-Notes/releases) 页面下载 `mefistofele-mac.zip` 并解压。
2. 打开**终端**，输入 `chmod +x `（注意末尾有空格），把 `mefistofele` 文件拖进窗口后按回车。然后去掉 `chmod +x ` 再做一次即可运行。
   如果 macOS 阻止运行（“无法打开，因为无法验证开发者”）：执行 `xattr -d com.apple.quarantine ` 并跟上文件路径，或前往**系统设置 → 隐私与安全性 → 仍要打开**。
3. 第一次运行时，macOS 会询问**终端是否可以控制 Microsoft PowerPoint**：点击**好**（之后可在**系统设置 → 隐私与安全性 → 自动化**中更改）。

**然后（两个系统相同）**
- 浏览器会打开**管理页面**，并显示二维码。请用手机扫描。
- 在 PowerPoint 中开始放映（**幻灯片放映 → 从头开始**）：备注会显示在手机上并随幻灯片同步。

程序运行在黑色窗口中（Mac 上是终端）：**关闭该窗口即可停止程序**。

## 管理页面（在电脑上）
地址：`http://localhost:8080/start`（自动打开）。右上角的**指南**按钮会以所选语言打开本手册。

**语言。** 在**语言**菜单中选择：English（默认）、Italiano、Français、Español、العربية 或 中文。
该设置适用于管理页面、**所有手机**上的远程页面（它们跟随管理页面）以及指南。所选语言会被保存。

**二维码使用的网卡。** 如果电脑有多块网卡（例如 Wi-Fi 和制作网络），请在
**二维码使用的网卡**菜单中选择手机所连接的那一块：二维码和地址会立即更新。选择*自动*则由程序决定。

然后选择**手机上显示的内容**。各项按顺序如下：

| 选项 | 对手机的影响 |
|---|---|
| 工具栏 | 手机显示彩色按钮栏，以及顶部条和锁。**关闭时**，手机只显示下面选中的项目，且**不能更改任何内容** |
| 文字样式 | 字体、字号、颜色、行距、字距 |
| 当前幻灯片 | 观众正在看的幻灯片图像 |
| 下一张幻灯片 | 下一张幻灯片的图像 |
| 跳转到幻灯片 | 数字框和**跳转**按钮，用于跳到指定幻灯片 |
| 导航 | 大号的**下一页**和**上一页**按钮 |
| 锁定远程屏幕 | 移除手机上的**所有控件**：只保留备注（超出屏幕时只能**滚动**）以及所选的预览。不再接受任何指令 |

您还可以为控制功能设置 **PIN**：第一次点击下一页/上一页或跳转时，手机会要求输入。
您的选择会被**保存**（程序旁边的 `mefistofele.json`），并**立即**同步到已连接的手机。
管理页面**只能在运行程序的电脑上**打开。

## 远程页面（在手机上）
每个功能都有自己的颜色。**实心**按钮 = 开启，**仅有轮廓**的按钮 = 关闭。

| 颜色 | 按钮 | 作用 |
|---|---|---|
| 紫色 | 文字样式 | 显示/隐藏文字控件 |
| 绿色 | 导航 | 显示/隐藏上一页/下一页和跳转到幻灯片 |
| 橙色 | 当前幻灯片 | 显示/隐藏当前幻灯片预览 |
| 蓝色 | 下一张幻灯片 | 显示/隐藏下一张幻灯片预览 |
| 青色 | 全屏 | 进入/退出全屏（iPhone 不支持） |
| 红色 | 锁定屏幕 | 锁定手机，防止误触 |
| 灰色 | 二维码 / 信息 | 用于连接另一部手机的二维码 / 版本、指南和制作信息 |
| 黄色 | 隐藏工具栏 | 关闭工具栏 |

**文字大小**：在框中输入数字，或使用 **a−**（更小）和 **A+**（更大）。

**顶部条。** 关闭工具栏后会保留一个带四个按钮的顶部条：**工具栏**（重新打开）、
**屏幕**（全屏开/关）、**导航**（显示/隐藏上一页、下一页和跳转）以及**锁定**。

**锁定屏幕。** 使用锁后，屏幕会忽略所有触摸（备注仍会更新）。
要**解锁，请长按顶部红色按钮 5 秒**：进度条填满后屏幕即解锁。提前松手则仍保持锁定。

页面打开期间，**手机不会进入待机**。首次点击页面会启用该保护；
如果手机仍然熄屏，请检查是否开启了*省电模式*。

底部：大号的**上一页**和**下一页**按钮，以及用于跳到某张幻灯片的**跳转**框。
如果同时打开了多个演示文稿，请在**演示文稿**菜单中选择要跟随的那个（*锁定远程屏幕*时不可用）。
每部手机会记住自己的选择（文字样式、显示内容）。语言以管理页面中所选为准。

## 命令行选项
Windows：`mefistofele.exe --port 8080 --pin 1234 --no-control --no-browser --demo`
Mac：`./mefistofele --port 8080 --pin 1234 --no-control --no-browser --demo`

- `--port` 服务器端口（默认 8080）
- `--pin` 控制功能的 PIN
- `--no-control` 完全关闭手机上的控制功能
- `--no-browser` 不在电脑上打开管理页面
- `--demo` 无需 PowerPoint 即可试用

## 故障排除
- **手机无法连接**：是否在同一网络？如果电脑有多块网卡，请在管理页面中选择正确的一块。Windows 防火墙：允许*专用网络*（如果 Wi-Fi 被识别为公用网络，也要允许公用网络）。在 Mac 上如有提示，请允许传入连接。
- **不显示备注**：幻灯片放映必须**正在进行**（全屏），而不仅仅是打开文件。
- **Mac：没有反应**：检查**系统设置 → 隐私与安全性 → 自动化**，确认终端被允许控制 Microsoft PowerPoint。
- **幻灯片预览**：在 Mac 上取决于 PowerPoint 是否允许导出；如果失败，原因会显示在图片位置，备注和控制功能仍可正常使用。
- **没有预览（Windows）**：打开 `http://localhost:8080/diagnostica`，点击测试按钮并复制全部内容。
- 错误也会写入程序旁边的 `mefistofele.log`（或临时文件夹）。
